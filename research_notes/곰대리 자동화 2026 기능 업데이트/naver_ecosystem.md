## 1. 네이버 검색 변화: AI 브리핑, AI탭/에이전트 N, 통합검색·스마트블록, C-Rank/D.I.A.

### Takeaway
2025~2026년 네이버 검색은 '문서 목록'에서 'AI가 출처를 골라 답하는 구조'로 넘어갔다. AI 브리핑(2025.3 도입)은 2026년 6월 기준 통합검색 쿼리의 약 27%에 적용됐고 연내 40%가 목표다. 2026.6.26에는 대화형 'AI탭'이 정식 출시됐고, 2026.9.17에는 네이버지도 '플레이스 에이전트'가 나왔다. 랭킹 축도 '키워드 일치·최신성'에서 '출처 신뢰도·직접 경험'으로 옮겨가고 있다. 다만 통합랭킹 개편의 세부 내용은 공식 문서로 확인되지 않았다.

### Inferences
- AI 브리핑이 통합검색 쿼리의 27%→40%(목표)로, 그리고 쇼핑·로컬까지 넓어지면서, 소상공인 키워드(예: "OO동 미용실", "OO역 맛집")에서 블로그 글은 '클릭되는 문서'보다 'AI 답변의 근거'로 쓰이는 비중이 커질 가능성이 높다. 이 때문에 블로그 노출 순위 대신 AI 브리핑·AI탭·플레이스 에이전트에 **인용되는지**가 새 성과 지표가 된다.
- 플레이스 에이전트와 AI탭은 플레이스 정보, 방문자 리뷰, 블로그 후기를 함께 읽는다. 그래서 사장님 블로그와 플레이스 정보(메뉴·가격·영업시간)가 서로 맞는지가 AI 답변 품질과 노출에 직접 영향을 줄 것으로 보인다.
- 출처 분포 조사 결과는 서로 엇갈린다(블로그 46.5% 대 42.3% 대 UGC 70%). 측정 시기, 기기, 키워드 세트가 달라서다. 다만 공통 방향은 "블로그 비중은 여전히 크지만 지도·쇼핑·클립 같은 네이버 자체 서비스 인용이 늘고 있다"는 것이다.

## 2. AI 생성·자동 게시 콘텐츠에 대한 네이버 정책(약관, 운영정책, 저품질·어뷰징, 제재, AI 표시)

### Takeaway
네이버는 2018년부터 약관에서 매크로·로봇 등 **자동화된 수단으로 게시물을 올리는 행위를 금지**하고 있다. 2025~2026년에는 AI 대량 자동 포스팅과 카페 바이럴에 대한 제재 강화를 실제 조치로 옮겼다. 2026.1에는 AI로 만든 가짜 영수증 리뷰를 단속했고, 2026.7에는 대형 카페 10여 곳에 접근제한을 걸었다. ## 3. 공식 API 현황: 블로그·카페 글쓰기, 검색, 데이터랩, 검색광고(키워드 검색량)

### Takeaway
블로그 글쓰기 API는 **2020년 5월 종료**됐고 지금도 대체 수단이 없다. 카페 글쓰기 API는 네이버 로그인 토큰 방식으로 문서상 남아 있지만 오류 보고가 있다. 2026년 가장 큰 변화는 **검색·데이터랩 오픈API가 'NAVER API HUB'(2026.6.25 출시)로 옮겨간 것**이다. 개발자센터 신규 신청은 2026.7.31에 닫혔고 기존 키는 2027.6.30까지 쓸 수 있다고 정리돼 있다. 쇼핑·책 검색 API는 대체 없이 종료됐다고 한다. 키워드 검색량은 검색광고 API(키워드도구)가 사실상 유일한 공식 경로다.

### Inferences
- 블로그 자동 발행에는 **공식 경로가 없다**(2020 API 종료). 결국 시장의 블로그 '자동 게시' 도구는 브라우저 자동화나 매크로에 기대게 되는데, 이는 약관의 자동화 수단 금지 조항과 정면으로 부딪친다. 네이버가 허용하는 자동화 범위는 대체로 '읽기'(검색 API, 데이터랩, 검색광고 키워드도구)와 사람이 직접 하는 발행 사이의 보조 작업까지로 보인다.
- 곰대리의 '무료 블로그 키워드 분석'이 네이버 검색·데이터랩 오픈API를 쓴다면, **2027.6.30 전에 API HUB 키로 옮겨야** 한다. 쇼핑 검색 API에 의존한다면 이미 깨졌을 수 있다(2026.7.31 종료).
- 카페 글쓰기 API는 문서상 유일한 '공식 게시' 경로다. 다만 동작이 불안정하고, 공식 API로 올린 글이라도 다계정·광고성이면 2026.7과 같은 카페 단위 제재 대상이 될 수 있다.

### Gaps
- NAVER API HUB 공식 문서(네이버클라우드)의 대상 API 목록, 카페 글쓰기 API 포함 여부, 요금과 한도를 직접 확인하지 못했다(비공식 정리와 개발자 PR에 근거함).
- 검색광고 API 키워드도구의 공식 호출 한도 수치를 확인하지 못했다.

## 4. 블로그·에디터·클립·창작자 보상 신기능(2025~2026)

### Takeaway
2025~2026년 네이버가 블로그에 공식으로 넣은 큰 변화는 '에디터 속 AI 글쓰기'가 아니라 **AI 브리핑 인용에 따른 보상(네이버 메이트, 2026.6 베타)**이다. 클립은 2026년 크리에이터 프로그램을 연중 상시 운영 체제로 바꿔 최대 2만 명까지 늘렸고, 텍스트+이미지 게시물까지 수익화 범위를 넓혔다. 스마트에디터에 공식 AI 글쓰기 도구가 들어갔는지는 확인되지 않았다.

2026년 10월 기준 네이버는 (a) 자동화된 게시 수단을 약관으로 금지하고(2018~), 블로그 글쓰기 API도 막았으며(2020~), 대량 AI 포스팅·매크로·다계정 바이럴·AI 가짜 리뷰를 실제로 제재하고 있다(2026). 동시에 (b) AI 브리핑, AI탭, 플레이스 에이전트가 '직접 경험·신뢰 출처·최신 정보'를 인용하고, 메이트·클립·애드포스트로 그런 콘텐츠에 보상한다. 그래서 "키워드 하나 → 자동 작성 → 자동 게시"형 제품은 **'사장님이 검수하고 직접 발행하는 AI 코파일럿'**으로 방향을 바꾸는 편이 규정상으로도 성과상으로도 맞다.

### Inferences: 기능별 권고

**A. 피하거나 없애야 할 것(위험 높음)**
1. **무인 자동 발행(브라우저 매크로·자동 로그인·예약 대량 발행):** 약관의 자동화 수단 금지 조항에 걸리고, 2026년 제재 강화와도 충돌한다. 특히 짧은 간격의 대량 발행(사례: 2~3분 간격, 하루 100건)이 가장 먼저 탐지되는 패턴이다.
2. **다계정·VPN·IP 우회 운영, 남의 카페에 홍보글 자동 배포:** 2026.7 카페 단위 접근제한의 직접 표적이다. '네이버카페 자동화'가 외부 카페 바이럴이라면 가장 위험한 기능이다.
3. **리뷰 생성·영수증 리뷰 대행·체험단 대량 자동화:** 2026.1 제재로 리뷰 블라인드와 플레이스 AI 브리핑 삭제(재생성 불가 가능)가 걸린다. 고객 매장에 되돌릴 수 없는 피해가 생길 수 있다.
4. **같은 업종 고객들에게 비슷한 템플릿 글을 대량 생성:** 같은 제목·구조의 대량 생성 글이 사라진다는 현장 보고가 있고**[비공식]**, 신뢰도·독창성 중심 랭킹과도 맞지 않는다.
5. **댓글·공감·이웃 추가 자동화:** 어뷰징 탐지 대상이라는 업계 공통 견해**[비공식]**와 2018 약관 조항에 해당한다.

**B. 바꿔야 할 것**
1. **'자동 게시' → '초안 + 사장님 검수 + 사장님이 직접 발행':** 생성한 글을 에디터에 붙여넣는 보조 방식(서드파티 사례처럼 발행은 사용자가 직접)으로 바꾼다. 발행 빈도에 상한(예: 하루 1~2건)을 두고 무작위성을 주는 것은 탐지 회피 목적이 아니라 '정상 이용' 범위 안에 머물게 하기 위함이다.
2. **'키워드 하나 입력'을 '경험 인터뷰 입력'으로:** 메뉴, 가격, 시술 과정, 실제 손님 사례, 사장님 코멘트를 묻는 3~5문항 질문지를 받아 1인칭 경험 글을 만든다(AI 브리핑 인용 조건인 직접 경험·진정성).
3. **원본 사진 필수화:** 사장님이 찍은 매장·메뉴·작업 사진 업로드를 요구하고, AI 생성 이미지와 스톡 이미지는 기본값에서 뺀다. 원본 사진 가점은 공식 문서로 확인되지 않았지만, 경험·진정성 신호와 일치한다.
4. **답변형 구조:** 첫 문단에서 질의에 바로 답하고, 소제목·표·FAQ·영업시간·가격 같은 사실 정보를 명시한다(AI 브리핑 '읽기 쉬운 구조' 조건). 정보가 바뀌면 기존 글을 고칠 수 있게 **최신성 관리 알림**(예: 가격·메뉴 변경 시 관련 글 수정 제안)을 붙인다.
5. **키워드 분석의 데이터 소스 교체:** 검색 API·데이터랩은 API HUB 키로 옮기고(2027.6.30 전), 검색량은 검색광고 API를 쓴다. 쇼핑 검색 API에 의존하는 부분은 걷어낸다(2026.7.31 종료).

**C. 추가할 만한 것(기회)**
1. **AI 브리핑·AI탭 인용 모니터링:** 고객 키워드("OO동 미용실" 등)로 AI 브리핑과 플레이스 에이전트 답변에 내 블로그나 플레이스가 인용되는지 추적하는 리포트. 순위 대신 인용을 성과 지표로 삼는다. 메이트 선정 기준(인용 횟수)과도 맞는다.
2. **플레이스 정보 정합성 점검:** 블로그 본문, 스마트플레이스 정보, 리뷰 사이에서 영업시간·메뉴·가격 불일치를 찾아낸다. AI탭과 플레이스 에이전트가 이들을 함께 읽기 때문이다. 플레이스 AI 브리핑 노출 설정 점검 가이드도 함께 제공한다.
3. **리뷰 답글 초안 도우미(사장님 승인형):** 공식 기능이 확인되지 않은 빈자리다. 실제 리뷰 내용에 맞춘 답글 초안을 만들어 주고, 게시는 사장님이 직접 한다. 리뷰 '생성'이나 '유도 보상'은 금지 문구로 막는다.
4. **블로그→클립 변환 고도화(컷대장):** 클립이 2026년 수익화와 AI 브리핑 출처로 커지고 있다. 세로 영상과 텍스트+이미지 카드형 클립 둘 다 출력하고, 클립 크리에이터 지원 조건 안내를 붙인다.
5. **AI 생성물 표시 옵션:** AI 기본법(2026.1.22) 대응으로 생성 결과에 기계 판독 메타데이터를 넣고, "AI 도움을 받아 작성" 같은 문구를 선택해 넣을 수 있게 한다(법적 적용 범위는 자문 필요).
6. **사장님 소유 카페 운영 보조:** 외부 카페 바이럴 대신, 단골 커뮤니티를 운영하는 사장님에게 공지·이벤트 글 초안, 멤버 보상 운영 체크리스트, 카페 비즈센터 활용 가이드를 준다.
7. **AI 브리핑 검색광고(ADVoost) 안내:** 2026.7.21부터 AI 브리핑 지면에 광고가 붙는다. 광고 문안을 에이전트가 쓰므로, 광고주센터와 랜딩페이지 정보를 정리해 주는 기능이 쓸모 있다.
8. **경쟁 모니터링:** 네이버 '에이전트 N 포 비즈니스'(2025.11 청사진)가 정식 출시되면 Place/SNS 관리 기능과 겹친다. 출시를 추적할 항목으로 둔다.
