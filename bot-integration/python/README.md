# 파이썬 봇에 인증코드 붙이기 (3줄)

발급한 코드를 **파이썬 봇이 알아보게** 연결하는 방법입니다.
추가 설치(pip) 필요 없습니다 — 파이썬 표준 기능만 씁니다.

## 1. 파일 복사

`license_client.py` 파일을 **내 봇 파이썬 파일과 같은 폴더**에 넣습니다.
(6개 봇이 폴더가 다 다르면, 각 봇 폴더마다 이 파일 하나씩 복사)

## 2. 봇 코드 맨 위에 3줄 추가

내 봇의 `.py` 파일 **맨 위**에 이걸 붙입니다:

```python
from license_client import LicenseClient

client = LicenseClient(api_base="http://localhost:3000", bot_id="bot1")
if not client.ensure_licensed()[0]:
    raise SystemExit("인증되지 않았습니다.")
```

그 아래에 **원래 봇 코드를 그대로** 두면 됩니다. 끝.

### 봇마다 바꿀 것은 딱 하나
`bot_id` 만 봇마다 다르게:

| 봇 | 코드 |
|---|---|
| 1번 봇 | `bot_id="bot1"` |
| 2번 봇 | `bot_id="bot2"` |
| … | … |
| 6번 봇 | `bot_id="bot6"` |

> `api_base` 는 서버 주소입니다. 내 PC에서 서버를 돌리면 `http://localhost:3000` 그대로 두고,
> 나중에 인터넷에 올리면(배포) 그 주소(예: `https://내앱.vercel.app`)로 바꾸면 됩니다.

## 3. 실제 동작

봇을 켜면:

1. 처음엔 콘솔에 **"인증코드를 입력하세요"** 가 뜸 → 발급받은 코드 입력
2. 통과하면 봇 실행 ✅ (그리고 코드가 PC에 저장돼서 **다음부턴 자동 통과**)
3. 관리 화면에서 그 코드를 **정지**하면 → 다음 실행부터 봇이 안 켜짐

## 자주 묻는 것

- **코드를 매번 입력해야 하나요?** 아니요. 한 번 통과하면 저장돼서 다음부턴 자동입니다.
  (저장 위치: `%APPDATA%\MyBots\license_bot1.key`)
- **인터넷이 끊기면?** "서버에 연결할 수 없습니다" 가 뜨고 통과되지 않습니다.
  (잠깐 끊겨도 봐주는 방식이 필요하면 말씀해 주세요 — grace 기능 추가 가능)
- **창 없이 도는 봇이라 입력칸이 안 떠요.** 그럴 땐 코드를 직접 저장해두면 됩니다:
  `%APPDATA%\MyBots\license_bot1.key` 파일에 코드를 적어 저장.
- **한 코드로 봇 6개 다 되나요?** 네. 코드 1개로 6개 전부 통과합니다.

## 동작 확인 (서버 켠 상태에서)

```bash
python example_bot.py
```
코드를 물어보면 관리 화면에서 발급한 코드를 입력해 보세요.
