📌 컷대장이란? — 두 가지 모드
━━━━━━━━━━━━━━━━━━━━━━━━━━━

컷대장은 두 가지 방식으로 영상을 만듭니다. 화면 맨 위에서 골라요.

[모드 A] 🎬 주제로 AI 영상 만들기 — 주제 한 줄 → 전부 자동
  ✅ 대본 작성(AI) + 목소리 생성(TTS) + 배경/줌 + 강조 자막 + BGM
  ✅ 완성: 세로 1080x1920 mp4 (또는 캡컷 프로젝트)

[모드 B] ✂️ 내 영상 편집 — 직접 찍은 영상/기존 영상을 쇼츠로  ★v0.5 신규
  ✅ 말 안 하는 빈 구간(무음) 자동 컷
  ✅ 말한 내용을 자동으로 자막으로 (음성인식)
  ✅ 가로 영상도 세로 쇼츠로 자동 배치 (또는 원본 비율 유지)

원하면 mp4 대신(또는 함께) "캡컷 프로젝트"로도 뽑아서 캡컷에서 직접 손볼 수 있습니다.

준비물
  · Windows 10 또는 11 PC
  · 인터넷 (설치 때 필요)
  · (실전 품질용) 구글 Gemini API 키 — 무료 발급, 방법은 3부에

1부. 설치 — 최초 1회만, 5~10분
━━━━━━━━━━━━━━━━━━━━━━━━━━━

① 배포받은 압축파일(컷대장_v0.3.zip)을 원하는 폴더에 풉니다.
   예) 바탕화면\컷대장

② 압축 푼 곳에서  cutdaejang → windows  폴더로 들어갑니다.

③ 「1_설치.bat」 더블클릭
   자동으로 진행되는 것:
     · Python이 없으면 자동 설치
     · 영상 엔진(FFmpeg, 약 100MB) 자동 다운로드
     · 마지막에 자가진단 실행

   ⚠ 파란 창 "Windows의 PC 보호"가 뜨면
      → [추가 정보] 클릭 → [실행] (서명 없는 스크립트라 뜨는 정상 경고입니다)
   ⚠ Python을 이번에 새로 설치했다면
      → 창을 닫고 1_설치.bat 을 "한 번 더" 실행하세요.

④ 검은 창 마지막에  「진단 결과: 정상」 이 보이면 설치 끝!

2부. 첫 쇼츠 뽑기 — 3분이면 됩니다

① windows 폴더에서 「2_UI실행.bat」 더블클릭
   → 검은 창(서버)이 하나 뜨고, 잠시 후 브라우저에 컷대장 화면이 열립니다.
   ⚠ 검은 창은 절대 닫지 마세요. 닫으면 화면도 꺼집니다. (최소화는 OK)

【이미지: 컷대장 메인 화면】

② 화면에서 딱 3가지만:
   · 쇼츠 주제 입력  (예: 하루 10분 정리 습관)
   · 목소리: 「내장 음성 (무료)」 선택  ← 키 없이 바로 됩니다
   · 파란 [생성 시작] 버튼 클릭

③ 진행률이 올라갑니다: 대본 생성 → 목소리 합성 → 배경 준비 → 영상 렌더링
   완료되면 화면 안에서 영상이 바로 재생됩니다.

【이미지: 생성 완료 화면】

④ 완성 파일 위치:
   컷대장\cutdaejang\windows\jobs\(날짜폴더)\output.mp4

💡 목소리 3가지 차이
   · 내장 음성(무료) …… Windows에 들어있는 한국어 음성. 키 필요 없음. 로봇 느낌은 있음
   · Gemini(실전 품질) … 성우급 목소리 + "진짜 대본"까지 AI가 작성. 무료 키 필요 (3부)
   · 테스트 톤 ………… "삐-" 소리. 기계가 잘 도는지 점검용이니 평소엔 쓸 일 없음

3부. 실전 품질 켜기 — Gemini 무료 키 발급 (5분)
━━━━━━━━━━━━━━━━━━━━━━━━━━━

내장 음성은 대본이 고정 문구입니다. "주제에 맞는 진짜 대본 + 성우급 목소리"는
구글 Gemini 키를 넣어야 켜집니다. 무료로 시작할 수 있습니다.

① 브라우저에서  aistudio.google.com/apikey  접속 (구글 계정 로그인)
② 파란 [API 키 만들기 / Create API key] 버튼 클릭
③ 생성된 키 복사 (AIza… 로 시작하는 긴 문자열)
④ 컷대장 화면에서 목소리 「Gemini (실전 품질)」 선택
   → 나타나는 입력칸에 키 붙여넣기
   (키는 저장되지 않습니다. 프로그램 켜져 있는 동안만 사용돼요)
⑤ 보이스(Kore 등 8종) / 말투 스타일(정보형·텐션형·스토리형) 선택
   → 🔊 [미리듣기] 로 목소리 먼저 들어보기
⑥ [생성 시작]!

💡 꼭 알아두세요 (무료 키 사용 팁)
   · 무료 등급은 "분당 10회" 호출 제한이 있습니다.
     컷대장이 알아서 속도를 조절하므로 그냥 두면 됩니다.
     진행 중에 "분당 한도 조절 중 — N초 대기" 가 보이는 건 오류가 아니라 정상 동작!
     (문장 15개짜리 영상 기준 약 2분 소요)
   · 한 번 만든 문장은 컴퓨터에 저장(캐시)됩니다.
     같은 대본을 다시 만들면 호출 0회 = 추가 비용 없이 순식간에 끝납니다.
   · 목소리 생성이 끝내 실패하면 자동으로 다른 목소리(OpenAI → 내장 음성)로
     대체해서라도 영상을 완성하고, 화면에 "대체 생성됨" 표시를 남깁니다.

③ 출력 형태: [쇼츠(세로 9:16)] 또는 [원본 비율 유지]
④ 음성 인식 방식 고르기:
   · 내장 Whisper (무료·오프라인) — windows\5_영상편집_음성인식설치.bat 한 번 실행하면 사용 가능.
     처음 자막 만들 때 모델을 한 번 자동 다운로드. 이후 공짜 + 인터넷 없이도 됨. (많은 영상엔 이게 유리)
   · Gemini (내 키) — 설치 없이 바로. 단 구간마다 호출돼서 무료 등급은 조금 걸릴 수 있음.
⑤ [✂️ 편집 시작]

★ 대본을 이미 갖고 있다면 (v0.9 신규) — "📝 대본 직접 입력" 칸에 붙여넣기
   · 한 줄 = 자막 한 줄로 붙여넣으면, 음성 인식을 아예 건너뛰고(오인식·비용 0)
     그 대본을 영상 타이밍에 맞춰 자막으로 넣습니다.
   · 자막이 자꾸 틀리게 인식될 때, 또는 말이 없는 영상(내레이션 대본만 있는 b-roll)에 특히 좋아요.
   · 붙여넣으면 "음성 인식은 건너뜁니다" 표시가 뜨고, 다음 검토 화면에서 타이밍·줄을 다듬을 수 있어요.

무엇을 해주냐면:
   · 말 안 하는 조용한 구간을 찾아서 잘라냅니다 (영상이 짧고 템포 있게 바뀜)
   · 말한 내용을 알아듣고 자동으로 자막을 붙입니다 (타이밍은 딱 맞게)
   · 가로로 찍은 영상은 세로 쇼츠 화면에 자동으로 예쁘게 배치(위아래 흐린 배경)

⚠⚠ 중요 — 내레이션(말)이 없는 영상이면:
   "자동 자막 만들기" 체크를 반드시 해제하세요!
   배경음악만 있는 영상에 자동자막을 켜두면, 프로그램이 음악을 말로 착각해서
   "시청해주셔서 감사합니다" 같은 엉뚱한 자막을 만들 수 있습니다.
   (v0.5.4부터 이런 헛자막을 자동으로 걸러내지만, 말 없는 영상은 아예 꺼두는 게 확실합니다)
   · 말 없는 영상(브이로그·풍경·먹방 b-roll) → [자동 자막] 끄기 → 세로 쇼츠 변환만
   · 말하는 영상(리뷰·설명·인터뷰) → [자동 자막] 켜기

체크박스 2개:
   · [자동 자막 만들기] — 말한 내용을 자막으로 (말 없는 영상은 끄기)
   · [무음 구간 자동 컷] — 끄면 원본 길이 그대로 세로 변환만

★ 자막 수정 (v0.7~v0.9): 자동 자막(또는 입력 대본)이 나오면 바로 완성하지 않고 "자막 검토·수정" 화면이 뜹니다.
   · 틀린 자막을 그 자리에서 고치세요 (음성인식은 100%가 아니라 오타가 있을 수 있음)
   · 영상 플레이어가 위에 "고정"돼서 자막을 스크롤해도 항상 보입니다 (v0.9)
   · ▶ 재생 버튼 또는 스페이스바로 재생/정지 — 자막 따라가다 멈출 때 위로 안 올라가도 돼요 (v0.9)
   · 배속 0.75~2배로 빠르게 검토 (v0.9)
   · 재생하면 지금 말하는 자막 줄이 파랗게 표시되고 자동으로 따라갑니다 (v0.8.1)
   · 각 줄의 시간(0:02.1)이나 ▶ 를 누르면 그 지점부터 소리 재생
   · [⬆] 위 줄과 합치기 / [✂] 한 줄을 둘로 나누기 / [✕] 줄 삭제 / [+ 자막 줄 추가] (v0.9)
   · [📋 대본 일괄 붙여넣기] — 대본을 통째로 붙여넣어 자막 텍스트를 순서대로 한 번에 교체 (v0.9)
   · 💛 강조(노란 글씨) — 문장 끝에 「| 단어」를 붙이면 그 단어만 노란색으로 (v0.9.1)
     예)  안녕하세요 곰대리 곰부장입니다 | 곰대리   →  "곰대리"만 골드 강조
     (폰트는 Pretendard ExtraBold로 굵고 또렷하게 자동 적용)
   · 자막 칸을 클릭해 수정을 시작하면 영상이 자동으로 멈춥니다 (v0.9.1)
   · 다 고쳤으면 [✅ 이 자막으로 완성] → 렌더
   · 자막은 .srt 파일로도 저장돼서 다른 편집기에서도 쓸 수 있어요
   · 강조 색을 바꾸고 싶으면 [⚙ 설정] → "강조 색"에서 원하는 색으로

★ 상단 제목(훅) + AI 제목 추천 (v0.6~v0.8): 화면 위에 크게 계속 뜨는 제목을 넣을 수 있고,
   "✨ 제목 추천"으로 후킹 제목 여러 개를 AI가 지어줘 골라 넣을 수 있어요.

4부. 옵션 활용법
━━━━━━━━━━━━━━━━━━━━━━━━━━━

▶ 모드 — 자동 vs 검토
   · 자동(한 번에 완성): 클릭 1회로 끝. 대량 생산·테스트용
   · 검토(대본 확인 후): AI 대본이 먼저 화면에 나옵니다.
     - 한 줄 = 자막 한 줄 = 목소리 한 문장
     - 문장을 자유롭게 고치고 [이 대본으로 계속]
     - 노란색 강조 단어 바꾸기: 문장 끝에 세로줄로 표시
       예)  하루 십 분이면 충분합니다 | 십 분

▶ 배경음악 (BGM)
   ① 컷대장\cutdaejang\resources\bgm 폴더에 음원(mp3/wav)을 넣는다
   ② 화면의 BGM 목록에서 선택 (「랜덤」 선택 시 폴더에서 무작위)
   · 볼륨은 자동으로 목소리 아래(-20dB)로 깔리고, 영상 끝에서 자연스럽게 페이드아웃
   ⚠ 저작권 확인된 음원만 사용하세요! (유튜브 오디오 라이브러리 추천)

▶ 캡컷으로 내보내기 (수정하고 싶을 때)
   · 「캡컷 draft도 생성」 체크 → Drafts 폴더는 자동 감지
   · 완료 후 캡컷을 열면 cutdaejang_ 으로 시작하는 프로젝트가 보입니다
   · 배경·자막·목소리·BGM이 트랙별로 들어가 있어 자유롭게 수정 가능

▶ 히스토리
   · 화면 아래에 지난 작업 목록 + [▶재생] 버튼
   · 같은 영상 다시 만들 필요 없이 바로 확인

6부. 문제 해결 (FAQ)
━━━━━━━━━━━━━━━━━━━━━━━━━━━

Q1. 화면 위에 빨간 배너 "FFmpeg가 없습니다"
 → 1_설치.bat 을 먼저 실행하세요. (2_UI실행.bat이 자동으로 설치를 시작하기도 합니다)

Q2. "분당 한도 초과 — N초 후 자동 재시도" 가 떠요
 → 오류 아닙니다. 무료 키 제한에 맞춰 기다렸다 자동으로 이어서 합니다. 그대로 두세요.

Q3. "이 PC에 한국어 음성이 없습니다"
 → Windows 설정 → 시간 및 언어 → 음성 → 음성 추가에서 「한국어」 설치.
    또는 Gemini(실전 품질)를 사용하세요.

Q4. 목소리가 "삐—" 소리만 나요
 → 목소리가 「테스트 톤」으로 선택된 상태입니다. 「내장 음성」이나 「Gemini」로 바꾸세요.

Q5. Python 설치했는데도 안 돼요
 → 창을 전부 닫고 1_설치.bat 다시 실행. 그래도 안 되면 PC 재부팅 후 한 번 더.

Q6. 브라우저가 자동으로 안 열려요
 → 검은 창이 떠 있는 상태에서 브라우저 주소창에  127.0.0.1:7860  입력.

Q7. 생성이 실패로 끝났어요
 → 화면의 빨간 오류 문구(+ [자세히] 누른 화면)를 캡처해서 댓글/문의로 올려주세요.

Q7-1. "영상 렌더링 0%"에서 안 넘어가고 멈춰요
 → v0.4.3에서 이 "0% 정지" 버그를 수정했습니다(내부 처리 멈춤 현상). 최신 버전으로 덮어쓰세요.
 → 그래도 느리게 느껴지면: "배경 줌 효과" 때문입니다. 사양 낮은 PC는 60초 영상 기준
    1~5분 걸립니다. 검은 창을 닫지 말고 기다리세요. (진행 중이면 [생성 시작]이 회색)
 → 더 빨리: [⚙ 설정] → "배경 모션" [없음] → [설정 저장] → 다시 생성 (3배 가까이 빠름)
 → GPU가 있는 PC라면 자동으로 GPU 가속을 씁니다(더 빠름).

Q7-2. "API 오류 404 ... image-generation ... NOT_FOUND" 로 실패했어요
 → AI 배경 이미지 기능이 켜져 있었고, 그 모델을 못 찾아 난 오류입니다. v0.4.2부터는
    이 기능이 기본 꺼짐(항상 되는 그라데이션 배경 사용)이라 이 오류가 나지 않습니다.
    최신 버전으로 덮어쓰기만 하면 해결됩니다.
 → AI 배경을 꼭 쓰고 싶으면: [⚙ 설정] → "AI 배경 이미지 생성" 체크 → 저장.
    (실패해도 자동으로 기본 배경으로 넘어가 영상은 완성됩니다)

Q8. 완성 영상이 어디 갔는지 모르겠어요
 → 완료 화면의 [📂 폴더 열기] 버튼이 제일 빠릅니다.
    직접 찾으려면: 컷대장\cutdaejang\windows\jobs 폴더 안, 날짜 이름 폴더의 (제목).mp4
