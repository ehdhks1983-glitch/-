   · [📋 대본 일괄 붙여넣기] — 대본을 통째로 붙여넣어 자막 텍스트를 순서대로 한 번에 교체 (v0.9)

▶ 모드 — 자동 vs 검토
   · 자동(한 번에 완성): 클릭 1회로 끝. 대량 생산·테스트용
   · 검토(대본 확인 후): AI 대본이 먼저 화면에 나옵니다.
     - 한 줄 = 자막 한 줄 = 목소리 한 문장

     - 노란색 강조 단어 바꾸기: 문장 끝에 세로줄로 표시
       예)  하루 십 분이면 충분합니다 | 십 분

▶ 배경음악 (BGM)
   ① 컷대장\cutdaejang\resources\bgm 폴더에 음원(mp3/wav)을 넣는다

   · 볼륨은 자동으로 목소리 아래(-20dB)로 깔리고, 영상 끝에서 자연스럽게 페이드아웃
   ⚠ 저작권 확인된 음원만 사용하세요! (유튜브 오디오 라이브러리 추천)

▶ 히스토리
   · 화면 아래에 지난 작업 목록 + [▶재생] 버튼
   · 같은 영상 다시 만들 필요 없이 바로 확인

6부. 문제 해결 (FAQ)
━━━━━━━━━━━━━━━━━━━━━━━━━━━

Q1. 화면 위에 빨간 배너 "FFmpeg가 없습니다"
 → 1_설치.bat 을 먼저 실행하세요. (2_UI실행.bat이 자동으로 설치를 시작하기도 합니다)

Q2. "분당 한도 초과 — N초 후 자동 재시도" 가 떠요
 → 오류 아닙니다. 무료 키 제한에 맞춰 기다렸다 자동으로 이어서 합니다. 그대로 두세요.

Q3. "이 PC에 한국어 음성이 없습니다"
 → Windows 설정 → 시간 및 언어 → 음성 → 음성 추가에서 「한국어」 설치.
    또는 Gemini(실전 품질)를 사용하세요.

Q4. 목소리가 "삐—" 소리만 나요
 → 목소리가 「테스트 톤」으로 선택된 상태입니다. 「내장 음성」이나 「Gemini」로 바꾸세요.

Q5. Python 설치했는데도 안 돼요
 → 창을 전부 닫고 1_설치.bat 다시 실행. 그래도 안 되면 PC 재부팅 후 한 번 더.

Q6. 브라우저가 자동으로 안 열려요
 → 검은 창이 떠 있는 상태에서 브라우저 주소창에  127.0.0.1:7860  입력.

Q7. 생성이 실패로 끝났어요
 → 화면의 빨간 오류 문구(+ [자세히] 누른 화면)를 캡처해서 댓글/문의로 올려주세요.

Q7-1. "영상 렌더링 0%"에서 안 넘어가고 멈춰요
 → v0.4.3에서 이 "0% 정지" 버그를 수정했습니다(내부 처리 멈춤 현상). 최신 버전으로 덮어쓰세요.
 → 그래도 느리게 느껴지면: "배경 줌 효과" 때문입니다. 사양 낮은 PC는 60초 영상 기준
    1~5분 걸립니다. 검은 창을 닫지 말고 기다리세요. (진행 중이면 [생성 시작]이 회색)
 → 더 빨리: [⚙ 설정] → "배경 모션" [없음] → [설정 저장] → 다시 생성 (3배 가까이 빠름)
 → GPU가 있는 PC라면 자동으로 GPU 가속을 씁니다(더 빠름).

Q7-2. "API 오류 404 ... image-generation ... NOT_FOUND" 로 실패했어요
 → AI 배경 이미지 기능이 켜져 있었고, 그 모델을 못 찾아 난 오류입니다. v0.4.2부터는
    이 기능이 기본 꺼짐(항상 되는 그라데이션 배경 사용)이라 이 오류가 나지 않습니다.
    최신 버전으로 덮어쓰기만 하면 해결됩니다.
 → AI 배경을 꼭 쓰고 싶으면: [⚙ 설정] → "AI 배경 이미지 생성" 체크 → 저장.
    (실패해도 자동으로 기본 배경으로 넘어가 영상은 완성됩니다)

Q7-3. 편집 모드에서 Gemini로 자막 만들 때 "호출 오류"가 자꾸 나요
 → Gemini 자막(STT)은 발화 구간마다 API를 불러서, 무료 등급(분당 10회) 한도에
    금방 걸립니다. 해결: 음성 인식을 [내장 Whisper]로 바꾸세요. 무료 + 오프라인 +
    호출 제한 없음이라 긴 영상도 문제없어요. (windows\5_영상편집_음성인식설치.bat 1회 실행)
 → Gemini 키는 자막보다 ① AI 대본 ② 성우 목소리 ③ 쇼츠 AI 핵심 추천에 쓰세요.

Q7-4. 3분 영상을 넣었는데 무음만 잘리고 2분이라 쇼츠가 아니에요
 → 맞아요. 무음 컷만으론 길이가 크게 안 줄어요. 검토화면 "✂️ 쇼츠로 줄이기"에서
    넣을 핵심 자막만 ☑ 체크하고 나머지는 해제하세요 → 그 구간만 남겨 10~30초로 만듭니다.
    [✨ AI 핵심 추천]으로 목표 초를 정하면 자동으로 골라주기도 해요. (v0.10)

Q8. 완성 영상이 어디 갔는지 모르겠어요
 → 완료 화면의 [📂 폴더 열기] 버튼이 제일 빠릅니다.
    직접 찾으려면: 컷대장\cutdaejang\windows\jobs 폴더 안, 날짜 이름 폴더의 (제목).mp4

Q9. 4K로 만들어 올렸는데 유튜브에서 HD(1080p)까지만 나와요
 → 정상일 가능성이 높습니다. 순서대로 확인하세요:
   ① 업로드 직후엔 유튜브가 저화질부터 처리합니다. 4K(2160p)는 영상 길이에 따라
      수십 분~몇 시간 뒤에 화질 목록에 나타나요. 기다렸다가 다시 확인!
   ② 쇼츠 플레이어는 휴대폰 기종·앱 상태에 따라 1080p까지만 보여주는 경우가 많습니다
      (TV·태블릿·일부 기기는 그 이상). 시청자 대부분이 1080p로 보는 게 현실이에요.
   ③ 그래도 4K 업로드가 의미 있는 이유: 유튜브는 고해상도 업로드에 더 좋은 코덱(VP9/AV1)과
      높은 비트레이트를 배정해서, 같은 1080p로 봐도 눈에 띄게 선명합니다.
      → 컷대장의 「초고화질(4K)」는 이 목적입니다. 계속 4K로 올리는 걸 권장!

Q10. 무료로 쓸 수 있는 배경음악(음원)은 어디서 구하나요?

Q12. 완전 무료로 내 목소리 쓰기 — GPT-SoVITS 설치·연결 (v0.28)
 → 무료 오픈소스 GPT-SoVITS를 내 PC에 한 번만 설치하면, 참조 녹음 5~10초만으로
   학습 없이(zero-shot) 내 목소리 내레이션이 됩니다. 돈 안 들고 인터넷도 필요 없어요.
   ① 설치(한 번만): github.com/RVC-Boss/GPT-SoVITS 의 릴리즈에서 Windows
      통합패키지(GPT-SoVITS-...beta.7z, 수 GB)를 받아 압축 해제
      (그래픽카드 없어도 CPU로 동작 — 문장당 몇 초~수십 초로 느려질 뿐)
   ② API 서버 켜기: 압축 푼 폴더에서 go-apiv2.bat 실행 (없으면 주소창에 cmd 입력 후
      → runtime\python.exe api_v2.py 입력) — "9880" 이 보이면 성공. 창은 켜둔 채로!
   ③ 컷대장 연결: 첫 화면의 [🎤 내 목소리 등록] 버튼 (v0.37부터 첫 화면에 바로!) →
      방법 A에 참조 녹음(5~10초, 조용한 곳에서 또박또박) + 그 녹음에서 말한 문장
      → [등록(저장)] → 옆의 [🔊 미리듣기]로 확인
   ④ 사용: 보이스 목록 「🎤 내 목소리 (무료·내 PC)」 선택 → 🔊 미리듣기로 확인!
   💡 더 똑같은 목소리를 원하면: GPT-SoVITS의 WebUI(go-webui.bat)에서 내 녹음
      1~3분으로 한 번만 학습(파인튜닝)하면 품질이 확 올라갑니다. 학습은 딱 한 번!
   ⚠ 서버(②)가 꺼져 있으면 컷대장은 자동으로 다른 목소리로 폴백해 영상은 완성돼요.
