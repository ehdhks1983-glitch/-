📌 컷대장이란?
━━━━━━━━━━━━━━━━━━━━━━━━━━━

주제 한 줄만 입력하면 아래를 전부 자동으로 조립해 주는 프로그램입니다.

  ✅ 대본 작성 (AI가 훅-본문-CTA 구조로)
  ✅ 문장별 목소리 생성 (TTS)
  ✅ 세로형 배경 + 천천히 줌 되는 모션
  ✅ 자막 (핵심 단어는 노란색 강조, 발화와 딱 맞는 타이밍)
  ✅ 배경음악 깔기 (볼륨 자동 조절 + 끝에서 페이드아웃)
  ✅ 완성: 업로드 준비된 세로 1080x1920 mp4

원하면 mp4 대신(또는 함께) "캡컷 프로젝트"로도 뽑아서 캡컷에서 직접 손볼 수 있습니다.

준비물
  · Windows 10 또는 11 PC
  · 인터넷 (설치 때 필요)
  · (실전 품질용) 구글 Gemini API 키 — 무료 발급, 방법은 3부에

━━━━━━━━━━━━━━━━━━━━━━━━━━━
1부. 설치 — 최초 1회만, 5~10분
━━━━━━━━━━━━━━━━━━━━━━━━━━━

① 배포받은 압축파일(컷대장_v0.3.zip)을 원하는 폴더에 풉니다.
   예) 바탕화면\컷대장

② 압축 푼 곳에서  cutdaejang → windows  폴더로 들어갑니다.

③ 「1_설치.bat」 더블클릭
   자동으로 진행되는 것:
     · Python이 없으면 자동 설치
     · 영상 엔진(FFmpeg, 약 100MB) 자동 다운로드
     · 마지막에 자가진단 실행

   ⚠ 파란 창 "Windows의 PC 보호"가 뜨면
      → [추가 정보] 클릭 → [실행] (서명 없는 스크립트라 뜨는 정상 경고입니다)
   ⚠ Python을 이번에 새로 설치했다면
      → 창을 닫고 1_설치.bat 을 "한 번 더" 실행하세요.

④ 검은 창 마지막에  「진단 결과: 정상」 이 보이면 설치 끝!

━━━━━━━━━━━━━━━━━━━━━━━━━━━
2부. 첫 쇼츠 뽑기 — 3분이면 됩니다
━━━━━━━━━━━━━━━━━━━━━━━━━━━

① windows 폴더에서 「2_UI실행.bat」 더블클릭
   → 검은 창(서버)이 하나 뜨고, 잠시 후 브라우저에 컷대장 화면이 열립니다.
   ⚠ 검은 창은 절대 닫지 마세요. 닫으면 화면도 꺼집니다. (최소화는 OK)

【이미지: 컷대장 메인 화면】

② 화면에서 딱 3가지만:
   · 쇼츠 주제 입력  (예: 하루 10분 정리 습관)
   · 목소리: 「내장 음성 (무료)」 선택  ← 키 없이 바로 됩니다
   · 파란 [생성 시작] 버튼 클릭

③ 진행률이 올라갑니다: 대본 생성 → 목소리 합성 → 배경 준비 → 영상 렌더링
   완료되면 화면 안에서 영상이 바로 재생됩니다.

【이미지: 생성 완료 화면】

④ 완성 파일 위치:
   컷대장\cutdaejang\windows\jobs\(날짜폴더)\output.mp4

💡 목소리 3가지 차이
   · 내장 음성(무료) …… Windows에 들어있는 한국어 음성. 키 필요 없음. 로봇 느낌은 있음
   · Gemini(실전 품질) … 성우급 목소리 + "진짜 대본"까지 AI가 작성. 무료 키 필요 (3부)
   · 테스트 톤 ………… "삐-" 소리. 기계가 잘 도는지 점검용이니 평소엔 쓸 일 없음

━━━━━━━━━━━━━━━━━━━━━━━━━━━
3부. 실전 품질 켜기 — Gemini 무료 키 발급 (5분)
━━━━━━━━━━━━━━━━━━━━━━━━━━━

내장 음성은 대본이 고정 문구입니다. "주제에 맞는 진짜 대본 + 성우급 목소리"는
구글 Gemini 키를 넣어야 켜집니다. 무료로 시작할 수 있습니다.

① 브라우저에서  aistudio.google.com/apikey  접속 (구글 계정 로그인)
② 파란 [API 키 만들기 / Create API key] 버튼 클릭
③ 생성된 키 복사 (AIza… 로 시작하는 긴 문자열)
④ 컷대장 화면에서 목소리 「Gemini (실전 품질)」 선택
   → 나타나는 입력칸에 키 붙여넣기
   (키는 저장되지 않습니다. 프로그램 켜져 있는 동안만 사용돼요)
⑤ 보이스(Kore 등 8종) / 말투 스타일(정보형·텐션형·스토리형) 선택
   → 🔊 [미리듣기] 로 목소리 먼저 들어보기
⑥ [생성 시작]!

💡 꼭 알아두세요 (무료 키 사용 팁)
   · 무료 등급은 "분당 10회" 호출 제한이 있습니다.
     컷대장이 알아서 속도를 조절하므로 그냥 두면 됩니다.
     진행 중에 "분당 한도 조절 중 — N초 대기" 가 보이는 건 오류가 아니라 정상 동작!
     (문장 15개짜리 영상 기준 약 2분 소요)
   · 한 번 만든 문장은 컴퓨터에 저장(캐시)됩니다.
     같은 대본을 다시 만들면 호출 0회 = 추가 비용 없이 순식간에 끝납니다.
   · 목소리 생성이 끝내 실패하면 자동으로 다른 목소리(OpenAI → 내장 음성)로
     대체해서라도 영상을 완성하고, 화면에 "대체 생성됨" 표시를 남깁니다.

4부. 옵션 활용법
━━━━━━━━━━━━━━━━━━━━━━━━━━━

▶ 모드 — 자동 vs 검토
   · 자동(한 번에 완성): 클릭 1회로 끝. 대량 생산·테스트용
   · 검토(대본 확인 후): AI 대본이 먼저 화면에 나옵니다.
     - 한 줄 = 자막 한 줄 = 목소리 한 문장
     - 문장을 자유롭게 고치고 [이 대본으로 계속]
     - 노란색 강조 단어 바꾸기: 문장 끝에 세로줄로 표시
       예)  하루 십 분이면 충분합니다 | 십 분

▶ 배경음악 (BGM)
   ① 컷대장\cutdaejang\resources\bgm 폴더에 음원(mp3/wav)을 넣는다
   ② 화면의 BGM 목록에서 선택 (「랜덤」 선택 시 폴더에서 무작위)
   · 볼륨은 자동으로 목소리 아래(-20dB)로 깔리고, 영상 끝에서 자연스럽게 페이드아웃
   ⚠ 저작권 확인된 음원만 사용하세요! (유튜브 오디오 라이브러리 추천)

▶ 캡컷으로 내보내기 (수정하고 싶을 때)
   · 「캡컷 draft도 생성」 체크 → Drafts 폴더는 자동 감지
   · 완료 후 캡컷을 열면 cutdaejang_ 으로 시작하는 프로젝트가 보입니다
   · 배경·자막·목소리·BGM이 트랙별로 들어가 있어 자유롭게 수정 가능

▶ 히스토리
   · 화면 아래에 지난 작업 목록 + [▶재생] 버튼
   · 같은 영상 다시 만들 필요 없이 바로 확인

5부. 자동으로 적용되는 퀄리티 기능 (v0.3 신규)
━━━━━━━━━━━━━━━━━━━━━━━━━━━

따로 켤 필요 없이 기본 적용됩니다.

   ✔ 배경 슬로우 줌 — 정지 이미지도 살아 움직이는 느낌
   ✔ 강조 자막 — 문장마다 핵심 단어 1개가 노란색으로
   ✔ 자막 스타일 상향 — 더 크고(76px) 두꺼운 외곽선, 쇼츠 하단 버튼과 안 겹치는 위치, 부드러운 등장
   ✔ 무음 컷 pacing — 문장 앞뒤 어색한 침묵을 자동으로 잘라 템포 유지
   ✔ 음량 표준화 — 유튜브 권장(-16 LUFS)으로 통일

【이미지: 강조 자막이 들어간 완성 화면】

(고급) 컷대장\cutdaejang\settings.json 파일을 메모장으로 열면
자막 크기, 줌 정도, BGM 볼륨, 문장 간격 등을 숫자로 바꿀 수 있습니다.
바꾼 뒤에는 검은 창을 닫고 2_UI실행.bat 을 다시 실행하세요.

6부. 문제 해결 (FAQ)
━━━━━━━━━━━━━━━━━━━━━━━━━━━

Q1. 화면 위에 빨간 배너 "FFmpeg가 없습니다"
 → 1_설치.bat 을 먼저 실행하세요. (2_UI실행.bat이 자동으로 설치를 시작하기도 합니다)

Q2. "분당 한도 초과 — N초 후 자동 재시도" 가 떠요
 → 오류 아닙니다. 무료 키 제한에 맞춰 기다렸다 자동으로 이어서 합니다. 그대로 두세요.

Q3. "이 PC에 한국어 음성이 없습니다"
 → Windows 설정 → 시간 및 언어 → 음성 → 음성 추가에서 「한국어」 설치.
    또는 Gemini(실전 품질)를 사용하세요.

Q4. 목소리가 "삐—" 소리만 나요
 → 목소리가 「테스트 톤」으로 선택된 상태입니다. 「내장 음성」이나 「Gemini」로 바꾸세요.

Q5. Python 설치했는데도 안 돼요
 → 창을 전부 닫고 1_설치.bat 다시 실행. 그래도 안 되면 PC 재부팅 후 한 번 더.

Q6. 브라우저가 자동으로 안 열려요
 → 검은 창이 떠 있는 상태에서 브라우저 주소창에  127.0.0.1:7860  입력.

Q7. 생성이 실패로 끝났어요
 → 화면의 빨간 오류 문구(+ [자세히] 누른 화면)를 캡처해서 댓글/문의로 올려주세요.

Q7-1. "영상 렌더링 0%"에서 한참 멈춘 것 같아요
 → 멈춘 게 아니라 "배경 줌 효과" 만드는 중입니다. 사양 낮은 PC는 60초 영상 기준 1~5분 걸립니다.
    검은 창을 닫지 말고 조금 기다리세요. (진행 중이면 [생성 시작] 버튼이 회색입니다)
 → 빨리 뽑고 싶으면: 아래 [⚙ 설정] → "배경 모션"을 [없음] 으로 바꾸고 [설정 저장] →
    다시 생성하면 렌더가 3배 가까이 빨라집니다. (움직임 없는 정지 배경)
 → GPU가 있는 PC라면 자동으로 GPU 가속을 씁니다(더 빠름).

Q8. 완성 영상이 어디 갔는지 모르겠어요
 → 완료 화면의 [📂 폴더 열기] 버튼이 제일 빠릅니다.
    직접 찾으려면: 컷대장\cutdaejang\windows\jobs 폴더 안, 날짜 이름 폴더의 (제목).mp4
