## 1. 프로젝트 개요

### 1.1 현재 수동 워크플로우 (완 실사용 기준)
```
[일반 영상]  AI 대본(웹) → 촬영/AI 영상 → 브루(자막) → 완성
[쇼츠]      위 과정 + 뒷배경 제작 → 캡컷(배경+영상 합성) → 완성
```

### 1.2 제품 한 줄 정의
> 주제만 입력하면 대본·TTS·배경·자막을 자동 조립해 **①수정 가능한 CapCut 프로젝트** 또는 **②업로드 준비 완료된 mp4**로 뽑아주는 Windows 프로그램

### 1.3 운영 모드 (자동화 수준 2단계)
| 모드 | 사람 개입 | 용도 |
|---|---|---|
| **검토 모드 (기본값)** | 대본 확정 클릭 1회 (+A안이면 캡컷 내보내기 1회) | 브랜드 채널, 품질 관리 |
| **자동 모드** | 주제 입력 후 클릭 1회 → 완성 | 무인 대량생산, 테스트 채널 |
- 자동 모드도 대본·산출물은 히스토리에 전량 저장 → 사후 검수 가능
- ⚠ **자동 업로드 기능은 제품 범위에서 의도적으로 제외** (유튜브 inauthentic content 정책 리스크 — §8 참조. 생산은 자동, 업로드는 선별 운영 권장)

### 1.4 이중 출력
| 출력 | 경로 | 특징 |
|---|---|---|
| **A. CapCut draft** | Timeline Spec → draft_builder → Drafts 폴더 | 캡컷에서 열어 미세수정 가능, 익숙한 워크플로우 |
| **B. mp4 직접 렌더** | Timeline Spec → render_engine(FFmpeg) → 완성 영상 | 캡컷 불필요, 완전 무인, 배치 생산 가능 |
- GUI에서 선택: [A만] [B만] [둘 다]
- 자막 스타일 프리셋은 공통 정의 → A/B 출력 간 시각적 일관성 유지

## 3. 시스템 아키텍처

### 3.1 파이프라인 (쇼츠 모드, 이중 출력)
```
[주제 입력] 또는 [대본 붙여넣기]
     ↓
[① script_generator]  Gemini → 구조화 JSON
     ↓
[② 대본 검토 GUI]  (자동 모드 ON이면 스킵)
     ↓
[③ tts_engine]  문장별 TTS 생성
     ↓
[④ timeline_calculator]  ffprobe 실측(μs) → Timeline Spec 확정
     ↓
[⑤ background_generator]  Gemini 이미지 1080×1920 or 사용자 이미지
     ↓
┌────────────────── Timeline Spec (IR) ──────────────────┐
│  출력 A                          출력 B                  │
│  [⑥a draft_builder]             [⑥b render_engine]     │
│  pyCapCut 4트랙 조립             FFmpeg 합성+ASS자막      │
│       ↓                              ↓                  │
│  Drafts 폴더 + 자가검증          mp4 + 싱크검증           │
│       ↓                              ↓                  │
│  캡컷에서 수정·내보내기           완성 (업로드 준비됨)      │
└─────────────────────────────────────────────────────────┘
```

### 3.2 Timeline Spec (IR) — 두 출력 경로의 단일 진실 원천
```json
{
  "mode": "shorts",
  "canvas": {"w": 1080, "h": 1920, "fps": 30},
  "duration_us": 58200000,
  "background": {"type": "image", "path": "bg.png"},
  "main_video": {"path": "main.mp4", "layout": "top", "scale": 0.9,
                 "fit": "trim", "short_policy": "freeze_last"},
  "audio": [{"path": "s01.m4a", "start_us": 300000, "end_us": 3100000}, "..."],
  "subtitles": [{"text": "...", "start_us": 300000, "end_us": 3100000}, "..."],
  "style": {"font": "Pretendard-ExtraBold", "size": 64,
            "outline": 3, "position": "bottom", "gradient_overlay": true}
}
```
- 검증·직렬화 후 jobs 테이블에 저장 → "재생성" 시 어느 출력으로든 재빌드 가능
- draft_builder·render_engine은 이 스펙만 읽음 (상호 독립, 어댑터 패턴)

### 3.3 타임라인 계산 (v1.1 유지)
문장별 TTS 길이 실측 → start/end 확정 → 자막=오디오 동일 timerange → 동기화 오차 0

### 3.4 모듈 구조
```
cutdaejang/
├── core/
│   ├── script_generator.py    # Gemini 대본 (Blog AI 이식)
│   ├── tts_engine.py          # 문장별 TTS + 캐싱
│   ├── timeline_calculator.py # Timeline Spec 생성
│   ├── background_generator.py# Gemini 이미지 (CafeMind 이식)
│   ├── draft_builder.py       # 출력 A: pyCapCut
│   ├── render_engine.py       # 출력 B: FFmpeg ★신규
│   │     ├── ass_writer.py    #   자막 .ass 생성
│   │     ├── audio_assembler.py#  TTS 클립+갭 → 단일 트랙
│   │     └── ffmpeg_composer.py#  필터그래프 빌드+실행
│   └── draft_manager.py
├── gui/ · db/ · utils/ (v1.1 동일)
└── resources/fonts/Pretendard-ExtraBold.ttf  # 동봉 ★신규
```

## 5. 모듈 상세 설계

### 5.1~5.3 script_generator / tts_engine / background_generator
v1.1 §5.1~5.3 동일 (구조화 JSON 대본, 문장 해시 캐싱, -16 LUFS 정규화, 1080×1920 배경, 하단 그라데이션 옵션)

### 5.4 draft_builder (출력 A)
v1.1 §5.4 동일: 4트랙(배경→영상→그라데이션→자막 / 오디오 별도), 배치 프리셋(상단·중앙·풀), μs 정수 통일, 어댑터 패턴
- 변경점: 입력이 Timeline Spec으로 통일

### 5.5 render_engine (출력 B) ★신규 핵심
**(1) audio_assembler** — 문장 클립 + 갭 무음을 concat 필터로 1회 재인코딩 병합 → `voice_full.m4a` (AAC 192k). 병합 후 ffprobe 길이 = spec duration 대조

**(2) ass_writer** — Timeline Spec → `.ass` 자막 파일
- Style: Fontname=Pretendard ExtraBold, 외곽선(Outline=3, BorderStyle=1), Alignment=2(하단 중앙), MarginV로 세로 위치
- Dialogue: μs → `h:mm:ss.cc` 변환, 문장별 1줄
- 스타일 값은 공통 프리셋에서 변환 (A안 캡컷 스타일과 시각 일치 목표)

**(3) ffmpeg_composer** — 필터그래프 조립·실행 (개념 명령):
```
ffmpeg -loop 1 -t {dur} -i bg.png  -i main.mp4  -i voice_full.m4a \
 -filter_complex "\
   [0:v]scale=1080:1920,setsar=1[bg]; \
   [1:v]scale=972:-2[mv]; \
   [bg][mv]overlay=(W-w)/2:{y_preset}[comp]; \
   [comp]subtitles=subs.ass:fontsdir=resources/fonts[v]" \
 -map "[v]" -map 2:a \
 -c:v libx264 -crf 19 -preset medium -pix_fmt yuv420p -r 30 \
 -c:a aac -b:a 192k -movflags +faststart  out.mp4
```
- 메인 영상 없음(정보형 쇼츠): overlay 단계 생략, 배경+자막만
- 영상이 spec보다 김: trim / 짧음: `short_policy`에 따라 마지막 프레임 정지(tpad) 또는 루프
- GPU 자동 감지: `h264_nvenc` 사용 가능 시 전환(crf→cq 매핑), 실패 시 libx264 폴백 — 센텀하이 GPU 노트북 번들과 시너지
- 진행률: `-progress pipe:1` 파싱 → GUI 진행바

**(4) 싱크·품질 자가검증** — 렌더 결과 ffprobe: 총길이 오차 ±50ms 이내, 오디오 스트림 존재, 해상도 일치. 실패 시 재시도 1회 후 오류 리포트

### 5.6 자동 모드 (오케스트레이터)
- `auto_mode=True`: ②검토 스킵, 실패 지점별 정책 — 대본 JSON 파싱 실패(1회 재생성), TTS 문장 실패(재시도 2회 후 작업 실패 처리), 렌더 실패(리포트)
- 모든 산출물(대본·오디오·배경·스펙·결과) 작업 폴더에 보존 → 히스토리에서 열람·재생성

### 5.7 draft_manager
v1.1 동일 (경로 자동 감지, 자가검증 3종, 재시작 안내)
