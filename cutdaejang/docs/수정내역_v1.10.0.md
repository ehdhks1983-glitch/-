# 컷대장 v1.10.0 수정 내역

## 긴 영상 진입 개선

- 첫 화면의 세 번째 추천 카드에 `긴 영상 (가로 16:9)`을 배치했습니다.
- 이 카드는 8분 30초 같은 풀영상을 한 번에 넣는 `구간 대본 영상`으로 바로 연결됩니다.
- AI 영상·사진 영상·블로그 영상은 `더 많은 만들기 도구`에 그대로 유지됩니다.
- 직접 입력 가능한 영상 길이 상한을 90초에서 1800초(30분)로 늘렸습니다.
- AI 영상의 직접 입력 길이와 저장·복원 상한도 1800초로 통일했습니다.

## v1.09 누락분 병합

- 몽타주 컷 지점이 발화 중간에 걸리면 가까운 무음 경계로 옮깁니다.
- 일반 자동 편집과 구간 대본 영상의 몽타주 경로에 모두 적용됩니다.
- 긴 영상 내레이션 파일은 40문장씩 부분 트랙을 만든 뒤 하나의 최종 트랙으로 합칩니다.
- 수십~수백 문장의 음성 파일을 FFmpeg 한 명령에 몰아 넣지 않아 Windows 명령줄 길이 제한을 피합니다.

## 기존 개선 유지

- v1.09의 연속 낭독 블록, 실제 무음 기준 문장 분리, 구간 경계 간격 보정은 유지됩니다.
- 쇼핑 이미지 수집·원본 후보 재시도·사진 반영 순서 기록 기능을 유지합니다.
- 기존 여섯 가지 만들기 기능은 삭제하지 않고 첫 화면 순서만 조정했습니다.
