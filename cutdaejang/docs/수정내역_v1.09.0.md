# 컷대장 v1.09.0 수정 내역

## 핵심 수정

- 긴 영상의 내레이션을 문장 단위가 아닌 연속 블록으로 합성합니다.
- 블록은 실제 무음 지점을 찾아 문장별 파일로 나누며, 안전한 분리 지점을 찾지 못하면 기존 문장 합성 방식으로 자동 복귀합니다.
- 분리 지점에 남은 무음과 프로그램의 문장 간격이 겹치지 않게 정리해, 이어 읽기가 불필요하게 느려지지 않습니다.
- 구간 영상의 앞뒤 여백과 전환 겹침 시간을 보정해 구간 경계에서도 일정한 호흡을 유지합니다.
- 각 구간 화면을 내레이션 목표 길이에 0.05초 오차 이내로 맞춰 경계마다 생기던 제각각인 정적 여백을 제거합니다.
- 쇼핑 페이지의 지연 로딩 이미지, `srcset`, 상대 주소, 확장자 없는 이미지 주소를 수집합니다.
- 원본 이미지 후보가 잘못됐을 때 작은 이미지로 끝내지 않고 다음 후보를 계속 시도합니다.
- 수집된 쇼핑 사진을 모두 영상에 배치하고, 실제 반영 순서를 `photo_manifest.json`에 기록합니다.

## 사용성 개선

- 첫 화면에는 자주 쓰는 쇼핑·내 영상 편집·AI 영상만 먼저 표시합니다.
- 사진·블로그·구간 영상은 「더 많은 만들기 도구」를 펼치면 그대로 사용할 수 있습니다.
- 쇼핑 만들기는 링크 수집을 첫 단계로 배치하고 API 검색 도구는 선택 기능으로 정리했습니다.
- 구간 영상의 고급 속도·BGM·전환·화질 설정은 접어 두되 기존 기능은 유지했습니다.
- 쇼핑 사진의 번호, 순서 변경, 삭제, 최종 반영 장수를 화면에서 확인할 수 있습니다.

## 호환성과 안전장치

- 기존 TTS 제공자와 문장별 캐시는 계속 사용할 수 있습니다.
- 연속 합성을 지원하지 않는 음성 제공자는 기존 방식으로 동작합니다.
- 긴 블록은 제한된 글자·문장 수로 자동 분할해 API 한도와 장시간 음성 드리프트를 줄였습니다.
- 원본 v1.08.0 ZIP과 사용자 작업 파일은 변경하지 않습니다.
