## 접수된 오류 (1~7)

### 1. 쿠팡 파트너스 링크 사진 수집 실패 — 미착수 · [최우선]
- 증상: 상품명·가격·설명은 수집됨 / 상품 사진 0장 / 화면 상단 빨간 오류
- 기대: 대표 사진 + 상세 사진 자동 수집
- 분석(2026-07-28): 사진이 죽는 지점이 **두 군데**인데 화면에서 구분이 안 됨
  - (가) 주소를 못 찾음 — `product_page._usable()`(256~258행)이 **사진 0장이어도
    제목 + 설명 30자면 성공으로 판정** → 사진 없이 통과
  - (나) 주소는 찾았는데 다운로드 전멸 — `download_images()`(352~354행)가
    **12,000바이트 미만·이미지로 안 읽히면 조용히 버림**. CDN이 403(HTML)을 주면
    전부 여기서 사라지고 화면엔 "자잘한 그림 N장 제외"로만 표시
- 확정에 필요한 것: **빨간 오류 문구 원문 한 줄** (`[직접 ?장 · 모바일 ? · 브라우저 ?]`
  단계 숫자 포함). 직접 0장 → (가), 직접 3장인데 결과 0장 → (나)
- 예정 수정: `_usable`이 사진 0장을 성공으로 치지 않게 / 다운로드 실패 사유를
  숫자로 화면 표시(403·너무 작음·이미지 아님) / 12,000바이트 하한 낮추기

### 2. 일반 상품 링크도 사진 수집 실패 — 미착수 · [최우선]
- 증상: 쇼핑몰에서 직접 얻은 상품 링크로도 사진 0장
- 판단: 쿠팡 파트너스만의 문제 아님 → 공통 이미지 수집·다운로드 경로 문제
- 처리: **1번과 같은 원인으로 보고 함께 수정**

### 3. 네이버 쇼핑커넥트 열기 버튼 작동 안 함 — 원인확정 · [높음]
- 증상: 눌러도 사이트가 안 열림 (네이버 API 키 미설정 상태와 무관하게 열려야 함)
- 원인(확정): `webui.py` 5667행 — 링크 `<a>`가 **`<summary>` 태그 안**에 있음.
  브라우저가 summary 안의 클릭을 **접기/펼치기 동작으로 먹어버림**.
  `event.stopPropagation()`으로는 막을 수 없는 기본 동작
- 예정 수정: 버튼을 summary 밖으로 빼거나 `window.open` + `preventDefault`
- 참고: 쿠팡 파트너스 열기 버튼도 같은 구조 → 함께 점검

### 4. Gemini 대본 요약 503 오류 — 조치 불필요(관찰)
- 12:39, 12:40 두 차례 `503 UNAVAILABLE` (구글 서버 혼잡)
- 프로그램이 원문 문장 사용으로 자동 대체 → **정상 동작**
- 반복되면 재시도 간격 확대 검토

### 5. FFmpeg AAC 출력 오류 — 보류(과거 로그)
- `Invalid argument`, `Nothing was written into output file`
- 7월 25일 로그. 이번 쇼핑 사진 문제와 연관 증거 없음. 재발 시 별도 확인

### 6. 연속 내레이션 블록 사이 목소리 톤 변화 — 원인확정 · [최우선]
- 측정: 1~3구간 140~144Hz / 4구간 169Hz / 5구간 195Hz / 6~7구간 145~158Hz
- 원인(확정): v1.11의 새 방식은 문장을 **블록(최대 40문장)으로 묶어 한 번에 합성**
  (`tts_engine._synth_continuity_block`). 블록 안에서는 톤이 이어지지만
  **블록이 바뀌는 순간 ElevenLabs가 새로 시작하며 음높이가 리셋**됨
- 현재 코드: 블록 경계에 `previous_text`/`next_text`를 넘기긴 함(1097~1100행)
  → 그런데 **원문 문장 1개뿐이라 문맥이 짧고, `seed`(음성 고정값)를 안 씀**
- 예정 수정: 블록마다 동일 seed 고정 + 앞뒤 문맥 300자까지 확장

### 7. 풀영상 구간 조립 경계 — 완료(검증 통과)
- 1분 41초 / 1920×1080 / 7개 구간, 경계 12.95·18.23·30.02·55.07·75.22·86.87초
- 모든 경계가 0.32~0.38초 균일 무음 중앙, 말 잘림·1초 이상 멈춤 없음
- **v1.09 무음 스냅이 작동한 결과**
- 남은 검증: 실제 8분 30초급 장시간 영상 (합성 블록이 더 많아짐)
