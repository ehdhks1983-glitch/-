## 🖥 EXE 설치 파일 만들기 (v1.49~)

회원에게는 **zip 대신 EXE 설치 파일**을 주는 게 편합니다 (더블클릭 → 설치 →
바탕화면 아이콘). 저(개발)는 리눅스에서 만들어 드리고, 회원님은 받은 EXE를
**Windows에서 먼저 테스트**하시면 됩니다.

- 만들어지는 것: `컷대장_설치_v1.49.0.exe` (약 1.4MB — 파이썬은 첫 실행 때
  자동 준비되므로 설치 파일 자체는 가볍습니다)
- 설치 위치: `사용자\AppData\Local\컷대장` (관리자 권한 없이 설치됨)
- 바탕화면 「컷대장」 아이콘 → 누르면 서버 검은 창 + 화면이 뜹니다
- 제거: 시작메뉴 「컷대장 제거」 (작업물·설정·API 키는 남습니다)

⚠ 백신 경고: 서명 안 된 설치 파일이라 SmartScreen이 «알 수 없는 게시자»
경고를 낼 수 있습니다. [추가 정보 → 실행]으로 넘어갑니다. 회원께도 이 점을
카페 글에 미리 적어 두면 문의가 줍니다. (정식 서명은 인증서 구매가 필요 —
나중에.)

## 🔑 정품 코드 만들기 (7일 체험 이후)

회원이 설치하면 **7일 무료 체험**이 시작됩니다. 그 뒤로는 화면이 잠기고
**정품 코드**를 요구합니다. 코드는 사장님이 직접 만듭니다.

### 코드 만드는 법 (판매자 전용 도구)

저장소 루트의 `make_license.py`로 만듭니다 (이 파일은 제품에 안 들어갑니다 —
회원에게 주면 안 됩니다):
```
python make_license.py 2026-12-31           # 그 날짜까지 쓸 수 있는 코드 1개
python make_license.py 2026-12-31 --n 20    # 20명분 (각자 다른 코드)
python make_license.py 평생                   # 영구 코드
```
나오는 코드 예: `CD-20261231-F383QU4RPGXH3M5J`

### 회원이 하는 것

첫 화면 잠금창(또는 체험 배지의 [정품 등록])에 코드를 붙여넣으면 바로 열립니다.

### ⚠ 솔직한 한계

프로그램이 파이썬 소스라 «완벽한» 복제 방지는 안 됩니다 (기술 아는 사람은
우회 가능). 이 방식은 일반 회원의 무단 공유를 막는 실용적 수준입니다.
완전히 막으려면 서버 인증이 필요한데, 서버 운영 부담이 커서 지금은 넣지
않았습니다. 각 코드에 고유 번호가 들어가 있어, 유출된 코드가 돌면 어느
코드인지 추적은 됩니다.

카페 회원에게 나눠주고, 새 버전이 나오면 회원 화면에 자동으로 알려주는 방법.

## 회원이 겪는 흐름 (완성 모습)

1. 카페에서 zip 받기 → 압축 풀기 → `windows/1_설치.bat` 한 번 → `windows/2_UI실행.bat`
2. 실행하면 **주소창 없는 「컷대장」 전용 창**이 뜬다 (v1.18 — 브라우저 느낌 없음)
3. 새 버전이 나오면 **첫 화면에 자동으로** "🎁 새 버전 v○.○.○이 나왔어요 → 받기" 안내
4. 회원은 새 zip을 받아 **업데이트.bat에 끌어다 놓기(또는 더블클릭)** —
   설정·API 키·글씨체·효과음·FFmpeg은 그대로 두고 프로그램만 교체된다

## 사장님이 하는 일 (버전 낼 때마다 5분)

### 준비 (최초 1회)

1. version.json을 올려둘 곳을 하나 정한다 — **직접 다운로드 주소**가 나오는 곳이면 어디든:
   - GitHub 공개 저장소(추천: raw.githubusercontent.com 주소가 안정적)
   - 구글 드라이브 직링크(`uc?export=download&id=...`)
2. `cutdaejang/update_url.txt` 파일을 열어 그 주소를 한 줄 넣는다:
   ```
   https://raw.githubusercontent.com/내계정/cutdaejang-release/main/version.json
   ```
   ⚠ 이 파일이 **주석뿐이면 확인 기능은 조용히 꺼져** 있다 (기본 상태).

### 새 버전을 낼 때마다

1. zip을 만들어 카페(또는 드라이브)에 올린다
2. version.json 내용을 갱신해 같은 자리에 올린다:
   ```json
   {
     "version": "1.19.0",
     "url": "https://다운로드주소/컷대장_v1.19.0_풀버전.zip",
     "note": "쇼핑 수집 안정화 + 쉬운 모드"
   }
   ```
3. 끝 — 회원 프로그램이 하루 한 번(또는 [🔄 새 버전 확인] 클릭 때) 이 파일을 읽고
   버전이 높으면 첫 화면에 다운로드 안내를 띄운다.

## 자주 묻는 것

- **회원 설정이 날아가지 않나?** — 업데이트.bat이 settings.json·api_keys.json·
  받아둔 글씨체·효과음·FFmpeg을 보존하고 프로그램 파일만 바꾼다.
- **version.json 주소가 죽으면?** — 회원 화면에 "확인 실패"만 조용히 표시되고
  프로그램 사용에는 아무 영향 없다.
- **버전 비교 규칙** — 숫자 3자리 비교(1.19.0 > 1.18.9). "v" 접두어 있어도 인식.
