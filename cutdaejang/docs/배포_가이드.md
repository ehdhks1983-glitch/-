# 📦 컷대장 배포 가이드 (사장님 전용) — v1.48 판매 준비판 기준

## ✅ 판매 전 체크리스트 (위에서 아래로, 5개)

1. □ **`cutdaejang/update_url.txt`에 version.json 주소 한 줄** — 아래 «준비 (최초 1회)».
     ⚠ 주소를 넣기 «전에» 그 주소가 실제로 열리는지 브라우저로 확인하세요.
     죽은 주소를 넣으면 모든 회원 화면에 «확인 실패»가 계속 뜹니다.
     (아직 주소가 없으면 비워 두세요 — 알림 기능만 꺼진 채 정상 동작합니다)
2. □ **`판매문서/환불·지원안내.txt`의 문의처 2줄** (카페 게시판 주소·이메일) 채우기
3. □ zip을 카페(또는 드라이브)에 올리고 **내려받기 주소 확보**
4. □ version.json을 만들어 1번 주소 자리에 올리기 (아래 «새 버전을 낼 때마다»)
5. □ `docs/카페가이드.txt`를 카페 판매글로 게시 (설치법·기능·시연이 다 들어 있음)

v1.48부터 구매자 zip에는 내부 문서(docs/)와 시험(tests/)이 **안 들어갑니다** —
회원에게 가는 건 프로그램 + 실행가이드.md + 판매문서/ 뿐입니다.

카페 회원에게 나눠주고, 새 버전이 나오면 회원 화면에 자동으로 알려주는 방법.

## 회원이 겪는 흐름 (완성 모습)

1. 카페에서 zip 받기 → 압축 풀기 → `windows/1_설치.bat` 한 번 → `windows/2_UI실행.bat`
2. 실행하면 **주소창 없는 「컷대장」 전용 창**이 뜬다 (v1.18 — 브라우저 느낌 없음)
3. 새 버전이 나오면 **첫 화면에 자동으로** "🎁 새 버전 v○.○.○이 나왔어요 → 받기" 안내
4. 회원은 새 zip을 받아 **업데이트.bat에 끌어다 놓기(또는 더블클릭)** —
   설정·API 키·글씨체·효과음·FFmpeg은 그대로 두고 프로그램만 교체된다

## 사장님이 하는 일 (버전 낼 때마다 5분)

### 준비 (최초 1회)

1. version.json을 올려둘 곳을 하나 정한다 — **직접 다운로드 주소**가 나오는 곳이면 어디든:
   - GitHub 공개 저장소(추천: raw.githubusercontent.com 주소가 안정적)
   - 구글 드라이브 직링크(`uc?export=download&id=...`)
2. `cutdaejang/update_url.txt` 파일을 열어 그 주소를 한 줄 넣는다:
   ```
   https://raw.githubusercontent.com/내계정/cutdaejang-release/main/version.json
   ```
   ⚠ 이 파일이 **주석뿐이면 확인 기능은 조용히 꺼져** 있다 (기본 상태).

### 새 버전을 낼 때마다

1. zip을 만들어 카페(또는 드라이브)에 올린다
2. version.json 내용을 갱신해 같은 자리에 올린다:
   ```json
   {
     "version": "1.19.0",
     "url": "https://다운로드주소/컷대장_v1.19.0_풀버전.zip",
     "note": "쇼핑 수집 안정화 + 쉬운 모드"
   }
   ```
3. 끝 — 회원 프로그램이 하루 한 번(또는 [🔄 새 버전 확인] 클릭 때) 이 파일을 읽고
   버전이 높으면 첫 화면에 다운로드 안내를 띄운다.

## 자주 묻는 것

- **회원 설정이 날아가지 않나?** — 업데이트.bat이 settings.json·api_keys.json·
  받아둔 글씨체·효과음·FFmpeg을 보존하고 프로그램 파일만 바꾼다.
- **version.json 주소가 죽으면?** — 회원 화면에 "확인 실패"만 조용히 표시되고
  프로그램 사용에는 아무 영향 없다.
- **버전 비교 규칙** — 숫자 3자리 비교(1.19.0 > 1.18.9). "v" 접두어 있어도 인식.
