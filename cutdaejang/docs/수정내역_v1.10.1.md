# 컷대장 v1.10.1 수정 내역

## 긴 영상 내레이션 흐름

- 자막 화면 폭에 맞춘 줄바꿈과 TTS 발화 문장 분리를 분리했습니다.
- `먼저 사람이 하는 / 업무를 하는 거였습니다`처럼 문장 중간에 들어간 일반
  줄바꿈은 `먼저 사람이 하는 업무를 하는 거였습니다` 한 문장으로 이어 읽습니다.
- 실제 문장부호와 한국어 종결어미는 문장 경계로 유지합니다.
- 연속 낭독 블록을 최대 40문장까지 묶어 긴 영상에서 화자·음높이·속도 변화가
  자주 생기지 않게 했습니다.
- 연속 낭독 뒤 추가하는 문장 간 무음은 기본 0.15초로 줄였습니다.

## 내레이션과 자막 동기화

- 구간별 영상에는 자막과 내레이션을 미리 굽지 않습니다.
- 모든 화면을 합친 뒤, 실제 TTS 클립 길이로 만든 하나의 시간표를 내레이션 배치와
  최종 자막 렌더 양쪽이 함께 사용합니다.
- 일부 구간을 다시 만들거나 TTS 제공자가 바뀌어 음성 길이가 달라져도 예전 자막
  시간이 남아 어긋나지 않습니다.

## 완성 영상 다시 편집

- 구간 영상 완료 화면의 `이 영상 편집`은 `오류 구간만 고치기`로 바뀝니다.
- 누르면 새 편집을 처음부터 시작하지 않고 기존 풀영상, 구간, 시간, 대본, 훅,
  목소리, 화질과 꾸미기 설정을 다시 불러옵니다.
- 수정 후 다시 만들면 바뀐 구간만 재제작합니다.
- 구간 영상 화질 선택이 항상 표준으로 덮이던 중복 설정도 제거했습니다.
