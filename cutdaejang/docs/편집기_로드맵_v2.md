# 컷대장 → 완성형 편집기 로드맵 (v2 기획)

- 목표: **캡컷·브루(Vrew) 수준의 완성형 쇼츠·롱폼 편집기**
- 방식: 큰 기능을 작은 단계로 쪼개 **하나씩** 추가 (각 단계는 그 자체로 쓸 수 있게)
- 작성 배경: 사용자 실제 워크플로우 = 직접 촬영한 튜토리얼/리뷰(1~3분) → 자동 자막 → 수정·편집 → 완성

## 현재 상태 (v0.6)

| 기능 | 상태 |
|---|---|
| AI 생성 모드 (주제→대본→TTS→배경→자막) | ✅ |
| 내 영상 편집 (무음컷 + 자동자막 + 세로 쇼츠) | ✅ |
| 상단 제목(훅) 오버레이 | ✅ |
| BGM (AI 모드) | ✅ |
| 자막 **수정** | ❌ ← 지금 가장 아픈 곳 |
| 속도 조절 / 편집모드 BGM / 롱폼 폴리시 | ❌ |

## 관찰된 문제 (사용자 실제 영상 기준)

1. **자막 정확도**: 대체로 맞지만 오인식 존재("랩네이드했나고"). → 고칠 수단 필요
2. **긴 구간 = 한 자막 오래 뜸**: 무음 기준 분할이라 5초 넘게 같은 자막. → 문장 단위 분할 필요
3. **자막 3줄 넘침**: 최대 글자수·줄바꿈 정리 필요

## 아키텍처 메모 (완성형으로 가려면)

- 지금 UI는 "입력→클릭→출력" 1회성. 편집기는 "생성 → **수정** → 미리보기 → 내보내기"

## 현실적 한계 (솔직히)

- 캡컷·브루의 **타임라인 드래그 편집, 키프레임, 수백 개 스티커/효과**는 브라우저 기반
  경량 도구로 완전 재현하기 어렵다. → 컷대장은 "자동화 + 핵심 수정"에 집중,
  세밀한 손질은 캡컷 draft 내보내기로 위임하는 하이브리드가 현실적.
- 자막 100% 정확은 어떤 STT도 불가 → **빠른 수정 UX**가 정답 (Phase 1).
