# 경쟁 분석: 알파컷(alphacut.video) vs 컷대장 — 대응 로드맵

작성: 2026-07-23 (컷대장 v0.74.4 기준)
근거: Threads 광고 캡처(사용자 제공) + 컷대장 코드 전수 확인(기술 부록 참고)

---

## 1. 알파컷 요약 — 광고에서 확인된 것

| 항목 | 내용 |
|---|---|
| 형태 | 웹 SaaS (설치 없음, 서버에서 제작) |
| 가격 | **쇼츠 1편당 300원** (외주 몇 만원 대비 저렴함을 강조) |
| 대상 | 기존 영상을 가진 유튜버 — **긴 영상 → 쇼츠 변환**이 중심 |
| 간판 기능 | ① **첫 3초 후킹**: HOOK(궁금증 자막) + CLIMAX(가장 재미있는 장면)를 앞에 배치 ② **AI 후킹 보이스**: 전문 성우풍 AI가 영상 앞에 소개 멘트 ③ **쇼츠 템플릿**: 트렌디한 배경+로고 디자인 갤러리 ④ AI 자동 자막 ⑤ 간단 편집(제목 수정·길이·비율 조절) |
| 소셜프루프 | "조회수 2100%", "크리에이터 3만 명" — *광고 주장(검증 불가), 참고만* |

핵심 관찰: 알파컷의 마케팅은 기능 나열이 아니라 **"조회수가 잘 나오는 쇼츠"** 하나에 집중한다.
그 근거로 내세우는 게 첫 3초 후킹(콜드오픈)과 후킹 보이스 — 즉 **리텐션 엔지니어링**이다.
(우리가 2026 숏폼 리서치에서 확인한 결론과 정확히 같은 방향.)

## 2. 기능 비교표 — 알파컷 광고 기능별 컷대장 현재 상태

| 알파컷 광고 기능 | 컷대장 | 비고 |
|---|---|---|
| 첫 3초 후킹 (HOOK+CLIMAX 콜드오픈) | 🟡 **부분** | 핵심구간 추출·훅 상단제목은 있으나 **따로 놀고**, 추출 결과는 시간순 유지(클라이맥스를 앞으로 안 당김). 재훅(15초) 없음 |
| AI 후킹 보이스 (성우 인트로 멘트) | ❌ **없음** | TTS는 본문 내레이션 전용. 앞에 붙는 짧은 소개 멘트 기능 없음 |
| 쇼츠 템플릿 (디자인 갤러리) | ❌ **없음** | "내 세팅 템플릿"(설정 저장)은 있으나, 미리 디자인된 배경+로고 갤러리는 없음. 단, 재료(훅/자막 스타일 6종·그림체 12종·톤 5종·폰트)는 알파컷보다 많음 |
| AI 자동 자막 | ✅ **있음** | Whisper 로컬(무료·무제한) + Gemini + 자동 교정까지 — 동급 이상 |
| 간단 편집: 제목 수정 | ✅ **있음** | 자막 검토·수정 화면(브루식), 훅 제목 수정·AI 추천 |
| 간단 편집: 길이 조절 | ✅ **있음** | 목표초 핵심추출·여러 쇼츠 분할·배속·앞뒤 트림 |
| 간단 편집: 비율 조절 | ✅ **있음** (v1.35 갱신) | 편집·사진 폼 «맨 위»에 세로/가로/원본 유지. 예전엔 세부 설정 안에 있었고 사진 모드에선 아예 숨겨져 있었다 (목록 64 ②) |
| 성과 분석 (조회수 추적) | ❌ **없음** | 유튜브 API 필요 — 백로그(아래) |

**요약: 알파컷 간판 3개 중 2개(콜드오픈·후킹 보이스)가 컷대장에 없다.**
그런데 그 2개를 만들 **재료는 이미 다 있다** — 핵심추출·훅추천·TTS·효과음·펀치인 전부 보유. 조립만 하면 된다.

## 3. 컷대장이 이미 이기는 것 (알파컷이 광고 못 하는 것)

| 차별점 | 내용 |
|---|---|
| 💰 **무료·무제한** | 알파컷 300원/편 = 하루 10편이면 월 9만원. 컷대장은 자기 무료 API 키로 **0원 무제한** |
| 🎤 **내 목소리 클로닝** | 녹음 하나로 나만의 AI 목소리 (ElevenLabs + 무료 GPT-SoVITS). 알파컷 광고에 없음 |
| 🤖 **주제 한 줄 → 완성** | 알파컷은 "기존 영상"이 있어야 함. 컷대장은 **영상이 없어도** 대본·목소리·배경·자막까지 완전자동 생성 |
| 🎨 **연출 재료 풍부** | 그림체 12종·마스코트 캐릭터·효과음 자동배치·펀치인 줌·톤 보정·인포 팝 |
| 📦 **5플랫폼 업로드 키트** | 유튜브+틱톡+인스타+네이버클립+스레드 제목·태그·설명 원클릭 |
| 🔒 **내 PC에서 로컬 실행** | 영상·대본이 외부 서버에 안 올라감 |

### 카페 홍보에 바로 쓸 포지셔닝 문구 (참고)
- "편당 300원? 컷대장은 **평생 무료·무제한**입니다 (내 무료 키로 직접 만드니까)"
- "기존 영상이 없어도 됩니다 — **주제 한 줄만 쓰면** 대본·목소리·배경·자막까지 완성"
- "**내 목소리**로 내레이션하는 쇼츠, 컷대장만 됩니다"
- "영상이 회사 서버로 올라가지 않아요 — **전부 내 PC 안에서** 만들어집니다"

## 4. 대응 로드맵 (우선순위·버전 제안)

> 원칙: 알파컷의 "리텐션 엔지니어링"은 **따라잡고**(P1), 시각 품질(P2)과 초보자 경험(P3)으로 **앞서간다**.
> 모든 릴리스는 기존 원칙 유지 — 전체 테스트 통과 후 zip 1개로 한 번에 배포.

### P1 = v0.75 「훅 팩」 — 알파컷 간판 직접 대응 ★다음 릴리스
1. **(a) 콜드오픈 "클라이맥스 먼저"** (편집·핵심추출 경로)
   - 완전 자동/핵심추출 시 옵션: 가장 센 2~3초 순간을 **맨 앞 티저**로 배치 → 본편 시간순 재생
   - 재사용: `suggest_highlights`(핵심 선별) + `rebuild_from_keep`(재조립) — 티저-우선 순서만 추가
   - 주의: 현재 "앞 40% 몰림 거부" 가드는 콜드오픈 모드에서 예외 처리
2. **(b) AI 후킹 보이스** (편집·생성 공통)
   - 훅 1문장(`suggest_hooks` 재사용)을 TTS(`synth_with_fallback` 재사용)로 합성해 **영상 맨 앞에 프리펜드** + 훅 텍스트 슬램 + 띠링 효과음(기존 sfx)
   - 목소리는 사용자가 고른 내레이션 보이스 그대로 (내 목소리 클로닝이면 "내 목소리 후킹" = 알파컷도 없는 조합)
3. **(c) 14~15초 재훅** (AI 생성 경로)
   - 대본 프롬프트에 "1/4 지점 재훅 문장" 규칙 + rehook 플래그 → 해당 문장에 펀치인 줌+효과음 강조(기존 `orchestrator` 펀치인 로직 재사용)
   - 20초 미만 영상은 미적용
- 난이도: 중(조립 위주, 새 외부 의존성 0) / 임팩트: **매우 높음** — 알파컷 간판과 정면 대응 + 2026 리서치 1순위(첫 3초 이탈 50~60%)

### P2 = v0.76 「움직이는 b-roll」 — 시각 품질로 앞서기
- 문장별 영어 검색어(`broll_query`, 대본 스키마 확장) → **Pexels/Pixabay 무료 스톡 영상** 검색·다운로드 → 장면에 배치
- 신설 `broll_provider.py` + 기존 `scene_slideshow` 통합, AI그림과 **하이브리드**(구체 장면=영상, 추상=그림)
- 정책: **고급 옵션** (무료 Pexels 키 발급자만, Gemini 키처럼 발급 안내) — 키 없으면 지금처럼 AI그림 자동 폴백
- 폴백 체인: Pexels → Pixabay → AI그림 → 그라데이션 (절대 안 끊김)
- 임팩트: 정지그림 반복("AI 티") 탈피 — 리서치상 "정적 화면은 참여도를 죽인다" 직접 해결. 알파컷은 사용자 영상을 쓰므로 이 문제가 없음 → 컷대장 생성 경로의 최대 약점 보강

### P3 = v0.77 「쇼츠 템플릿 갤러리」 — 초보자 경험
- 기존 노브(훅 스타일·폰트·자막 스타일·톤·그림체·BGM·효과음) 조합을 **미리보기 카드 6~10종**으로 큐레이션 (예: "정보형 클린", "예능 자막빵", "릴스 팝", "시네마틱 스토리")
- 기존 "내 세팅 템플릿" 저장/불러오기 엔진 재사용 → 저비용
- 알파컷 "템플릿" 대응 + 초보 회원 "뭘 골라야 할지 모름" 해소

### 백로그 (보류 사유 명기)
- **성과/조회수 분석**: 유튜브 데이터 API 키·OAuth 필요 → 회원 진입장벽 큼. 우선 "업로드 키트+체크리스트"로 대체, 수요 확인 후 재검토
- **편집 모드 reels/wide 비율 추가**: P1에 곁들이기 좋은 소규모 작업 (편집 폼 layout 라디오 확장)
- 대본 글쓰기 톤 프리셋(현재 "정보형" 고정), AI 생성 경로 4K 화질 선택(현재 편집 전용), 디졸브 전환

## 5. 기술 부록 — 판정 근거 (다음 개발 세션용)

- 핵심구간 추출이 시간순 유지: `core/script_generator.py:267` (`sorted`), 앞 40% 몰림 거부 가드 `:270-278`(`front_only`), 휴리스틱도 `:396` `keep.sort()`
- 재조립 시간순: `core/edit_mode.py:623` (`rebuild_from_keep`, `sorted(key=start_us)`)
- 훅 = 전구간 고정 상단제목: `core/render_engine/ass_writer.py:161`(`hook_dialogue_text`), `:371-382`(0→duration 고정)
- "첫 3초"는 대본 문구 지시뿐: `core/script_generator.py:37`(PROMPT_TEMPLATE)
- TTS는 본문 전용(프리펜드 인트로 없음): `core/tts_engine.py:816`(`synth_all`), `:859`(`synth_with_fallback`)
- 인트로/아웃트로는 "브랜딩 범퍼 영상"만 존재: `core/video_editor.py:400`(`attach_branding`)
- 설정 템플릿(디자인 갤러리 아님): `gui/webui.py:2315`(`/api/template`), UI `:3151-3156`
- 편집 비율 shorts/keep만: `gui/webui.py:3497-3498`(`editLayout`), reels/wide는 생성 폼 `:3641`(`genOrient`)만
- 훅 추천(재사용 예정): `core/script_generator.py:191`(`suggest_hooks`, n=5)
- 펀치인(재훅에 재사용 예정): `core/orchestrator.py:332-346`
- 효과음 배치(후킹 보이스에 재사용 예정): `core/sfx.py:69`(`build_events` — 훅 시작 0.15s 띠링)
- 장면 슬라이드쇼(b-roll 통합 지점): `core/background_generator.py:360`(`scene_slideshow`)
- 성과 분석·A/B 부재: 저장소 전수 검색 결과 해당 기능 없음 (orchestrator의 "A/B"는 과거 출력경로 주석)
