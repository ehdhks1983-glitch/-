# 컷대장 실행가이드 — 직접 확인하는 법

Windows 10/11 기준. 아직 정식 설치파일(.exe)이 나오기 전 단계라서,
**더블클릭 2번**으로 확인할 수 있게 준비해 뒀습니다.
(정식 설치본은 기획안 Phase 3에서 Inno Setup으로 제작 예정)

---

## 방법 A. 받은 zip으로 (가장 쉬움)

1. 전달받은 `컷대장_v0.1.zip` 압축을 아무 폴더에나 풉니다. (예: `바탕화면\컷대장`)
2. `cutdaejang` 폴더 → `windows` 폴더로 들어갑니다.
3. **`1_설치.bat` 더블클릭** — 최초 1회만.
   - Python이 없으면 자동 설치를 시도합니다. Python을 새로 설치한 경우 창을 닫고 `1_설치.bat`을 **한 번 더** 실행하세요.
   - FFmpeg(약 100MB)을 자동으로 내려받습니다.
   - 마지막에 `진단 결과: 정상` 이 보이면 준비 끝.
4. **`2_데모실행.bat` 더블클릭.**
   - 십몇 초 뒤 폴더가 열립니다 → 날짜 폴더 안의 **`output.mp4`** 를 재생하세요.
   - 세로 1080×1920 영상에 한글 자막(프리텐다드)이 박혀 있으면 성공입니다.
   - ⚠ 데모의 목소리는 API 키 없이 돌리기 위한 **테스트용 "삐-" 톤**입니다. 진짜 목소리는 아래 "실전 실행" 참고.
5. (캡컷 설치된 PC라면) **`3_캡컷draft테스트.bat`** — 캡컷 프로젝트 목록에 `cutdaejang_...` 이 생기고 정상으로 열리는지 확인. 이게 기획안 PoC의 최중요 관문입니다. 결과(열림/안 열림, 자막 위치·크기)를 알려주세요.

## 방법 B. Cursor(또는 VS Code)에서

1. Cursor에서 `Ctrl+백틱(`)`으로 터미널을 열고:
   ```
   git clone -b claude/new-session-i6b7qn https://github.com/ehdhks1983-glitch/-.git cutdaejang-repo
   ```
2. `File → Open Folder`로 `cutdaejang-repo\cutdaejang` 폴더를 엽니다.
3. 터미널에서:
   ```
   windows\1_설치.bat
   windows\2_데모실행.bat
   ```
   (맥/리눅스라면: `brew install ffmpeg` 또는 `apt install ffmpeg` 후 `python3 -m cutdaejang demo`)
4. 코드 리뷰 포인트: `cutdaejang/spec.py`(설계의 심장인 Timeline Spec), `core/render_engine/`(mp4 직접 렌더), `docs/POC_REPORT.md`(검증 결과).

## 실전 실행 — 진짜 대본·진짜 목소리 (Gemini API 키 필요)

1. https://aistudio.google.com/apikey 에서 API 키 발급 (무료 시작 가능)
2. 명령 프롬프트에서 (cutdaejang 폴더 기준):
   ```
   set GEMINI_API_KEY=발급받은키
   set CUTDAEJANG_FFMPEG=%CD%\windows\ffmpeg\bin\ffmpeg.exe
   set CUTDAEJANG_FFPROBE=%CD%\windows\ffmpeg\bin\ffprobe.exe

   rem 자동 모드: 주제 → 완성 mp4 한 번에
   python -m cutdaejang run --topic "하루 10분 정리 습관" --auto --workdir windows\jobs

   rem 검토 모드(기본): 대본 먼저 뽑고, 파일 수정 후 재개
   python -m cutdaejang run --topic "하루 10분 정리 습관" --workdir windows\jobs
   python -m cutdaejang run --script-file windows\jobs\<작업폴더>\script.json --workdir windows\jobs
   ```
3. OpenAI 목소리로 바꾸려면: `set OPENAI_API_KEY=...` 후 `--tts openai` 추가.

## 문제가 생기면

- 아무 때나 `python -m cutdaejang doctor` — 무엇이 빠졌는지 한국어로 알려줍니다.
- `1_설치.bat`에서 FFmpeg 다운로드가 막히면: https://www.gyan.dev/ffmpeg/builds/ 에서
  release-full zip을 받아 압축 내용물을 `cutdaejang\windows\ffmpeg\` 에 넣으세요
  (`windows\ffmpeg\bin\ffmpeg.exe` 가 되도록).
- 화면 캡처와 함께 오류 문구를 그대로 보내주시면 다음 세션에서 바로 고칠 수 있습니다.
