# 컷대장 실행가이드 — 직접 확인하는 법

Windows 10/11 기준. **명령 입력 없이, 브라우저 화면(UI)에서 클릭으로** 확인하는 구조입니다.
(정식 설치파일 .exe는 기획안 Phase 3에서 Inno Setup으로 제작 예정)

---

## 방법 A. 받은 zip으로 (가장 쉬움)

1. `컷대장_v0.1.zip` 압축을 아무 폴더에나 풉니다. (예: `바탕화면\컷대장`)
2. `cutdaejang\windows` 폴더로 들어갑니다.
3. **`1_설치.bat` 더블클릭** — 최초 1회만.
   - Python이 없으면 자동 설치를 시도합니다. Python을 새로 설치했다면 창을 닫고 `1_설치.bat`을 **한 번 더** 실행하세요.
   - FFmpeg(약 100MB)을 자동으로 받고, 마지막에 `진단 결과: 정상`이 보이면 준비 끝.
4. **`2_UI실행.bat` 더블클릭** → 브라우저에 컷대장 화면이 열립니다.
   - 검은 콘솔 창은 서버라서 **닫지 말고 그대로** 두세요.
5. 화면에서:
   - 주제 입력 → **[생성 시작]** → 진행률 바(대본→TTS→배경→렌더링) → 완성되면 **화면 안에서 바로 재생**됩니다.
   - "테스트용 (키 불필요)" 모드의 목소리는 **"삐-" 톤**입니다 — 파이프라인 확인용.
   - **검토 모드**를 선택하면 대본이 먼저 나와서 문장을 직접 고친 뒤 [이 대본으로 계속]을 누릅니다.
   - **실전(진짜 대본+목소리)**: "Gemini (실전)" 선택 → API 키 입력란에 키 붙여넣기
     ([발급 링크](https://aistudio.google.com/apikey), 키는 저장되지 않고 이 실행 동안만 사용).
   - 캡컷이 설치된 PC라면 **"캡컷 draft도 생성"** 체크 → Drafts 폴더는 자동 감지됩니다.
     완료 후 캡컷에서 `cutdaejang_...` 프로젝트가 열리는지 확인해 주세요 (PoC 최중요 관문).

## 방법 B. Cursor(또는 VS Code)에서

1. Cursor 터미널(Ctrl+`)에서:
   ```
   git clone -b claude/new-session-i6b7qn https://github.com/ehdhks1983-glitch/-.git cutdaejang-repo
   ```
2. `File → Open Folder`로 `cutdaejang-repo\cutdaejang` 폴더를 엽니다.
3. 터미널에서:
   ```
   windows\1_설치.bat     ← 최초 1회
   windows\2_UI실행.bat   ← 브라우저 UI
   ```
   (맥/리눅스: `brew install ffmpeg` 또는 `sudo apt install ffmpeg` 후 `python3 -m cutdaejang ui`)
4. 코드 리뷰 포인트: `cutdaejang/spec.py`(Timeline Spec IR), `core/render_engine/`(mp4 직접 렌더),
   `gui/webui.py`(UI 서버), `docs/POC_REPORT.md`(검증 결과).

## 명령줄로 쓰고 싶을 때 (선택)

```
python -m cutdaejang doctor                 :: 환경 진단
python -m cutdaejang demo                   :: 콘솔 데모 (windows\4_데모실행_콘솔.bat 과 동일)
python -m cutdaejang run --topic "..." --auto
python -m cutdaejang render --spec jobs\<작업>\spec.json
```

## 문제가 생기면

- `1_설치.bat`의 FFmpeg 다운로드가 막히면: https://www.gyan.dev/ffmpeg/builds/ 에서
  release-full zip을 받아 내용물을 `cutdaejang\windows\ffmpeg\`에 넣으세요
  (`windows\ffmpeg\bin\ffmpeg.exe`가 되도록).
- UI가 안 뜨면 브라우저에서 직접 http://127.0.0.1:7860 접속.
- 화면 캡처와 오류 문구를 그대로 보내주시면 바로 고칠 수 있습니다.
